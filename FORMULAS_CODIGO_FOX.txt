1. PROCEDIMIENTO DE CÁLCULO DE HORAS EXTRAS Y GUARDIAS (líneas 1125-1158):
---------------------------------------------------------------------------

Este procedimiento calcula el promedio de Horas Extras y Guardias de los últimos 3 MESES:

```foxpro
procedure calculo
	*xper  = '0606'
	xper3 = 'mov_'+left(xper,2)+right(xper,2)+'.dbf'
	if !file (x_rem+xper3) then
		wait windows 'No existe datos de Horas Extras y Guardias, verifique...'
		return
	endif

	if val(left(xper,2)) = 1 then
		xper2 = 'mov_12'+right('0'+allt(str(val(right(xper,2))-1)),2)
		xper1 = 'mov_11'+right('0'+allt(str(val(right(xper,2))-1)),2)
	endif 	

	if val(left(xper,2)) = 2 then
		xper2 = 'mov_01'+right(xper,2)
		xper1 = 'mov_12'+right('0'+allt(str(val(right(xper,2))-1)),2)
	endif 	

	if val(left(xper,2)) > 2 then
		xper2 = 'mov_'+right('0'+allt(str(val(left(xper,2))-1)),2)++right(xper,2)
		xper1 = 'mov_'+right('0'+allt(str(val(left(xper,2))-2)),2)++right(xper,2)
	endif 	

	store 0 to HE, GR
	for x = 1 to 3
		xtab1 = 'xper'+allt(str(x))
		xtab2 = &xtab1
		xfile = x_rem+xtab2
		select 0
		use	&xfile alias tabla
		index on codigo_uni to d:\clave for codigo_mov='065'
		=seek(m.codigo_uni)
		HE = HE+tabla.importe
		index on codigo_uni to d:\clave for codigo_mov='066'
		=seek(m.codigo_uni)
		GR = GR+tabla.importe
		use 
	endfor
	HE = HE/3
	GR = GR/3
	!del d:\clave.idx
return
```

INTERPRETACIÓN:
- Busca movimientos de los últimos 3 meses (xper1, xper2, xper3)
- Código 065 = Horas Extras
- Código 066 = Guardias Nocturnas
- Suma los importes de los 3 meses y calcula el PROMEDIO (divide entre 3)
- Almacena en variables HE (Horas Extras) y GR (Guardias)

CONCLUSIÓN: Confirma que se calculan HORAS EXTRAS y GUARDIAS de 3 meses consecutivos
y se promedian (NO se toma 50% del último mes como dice la documentación).
